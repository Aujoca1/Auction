## 📖 ИНСТРУКЦИЯ ПОДКЛЮЧЕНИЯ ДРУЗЕЙ

Чтобы твои друзья могли играть с тобой, выполни следующие шаги:

### 1. Подготовка (Хост)
- Убедись, что вы все находитесь в одной сети (один Wi-Fi, точка доступа с телефона или Radmin VPN).
- Узнай свой локальный IP-адрес. В терминале введи `ipconfig`. Тебе нужен адрес вида `192.168.x.x` (обычно IPv4-адрес).

### 2. Запуск игры
- Запусти проект командой `npm run dev`.
- В терминале Vite напишет что-то вроде:
  `➜  Network: http://192.168.1.5:3000/`

### 3. Действия друзей
- Друзья должны ввести этот адрес (`http://192.168.x.x:3000`) в адресную строку своего браузера.
- На главной странице они должны выбрать **"Присоединиться"**, ввести имя и нажать **"Войти"**.

### 4. Если не подключается
- Проверь Брандмауэр Windows (Windows Firewall). Он может блокировать входящие подключения к порту 3000 и 3001. Попробуй временно его отключить или добавить порты в исключения.
- Если используете Radmin VPN, друзья должны вводить твой IP из программы Radmin.

## Обновление стабильности и порядка (24.03.2026):
- **Революция входа**: Теперь сначала вводится никнейм, который сохраняется в `localStorage`.
- **Умный реконнект**: Если игрок с таким ником уже есть в активной игре, появится кнопка «Вернуться в игру».
- **Строгий хостинг**: Кнопка «Присоединиться» больше не создает комнату. Игру создает только хост.
- **Управление лобби**: Добавлена возможность кикать игроков и кнопка полного роспуска комнаты (для хоста).
- **Исправление паса**: Лидер аукциона больше не может нажать «Пас». Добавлена 2-секундная задержка перед завершением раунда при всех пасанувших, чтобы дать шанс передумать.
- **Интерфейс**: Баланс в шапке теперь всегда актуален. Настройки в лобби меняются мгновенно. Убран автоматический таймер сброса игры в конце.
- **Адаптивность**: Список игроков в лобби теперь корректно отображается на телефонах.
- **Авто-возврат**: Приложение запоминает ваш ник и автоматически возвращает в игру при перезагрузке страницы, если вы уже были в комнате.
- **Исправление списка**: Устранена ошибка, когда новые игроки видели пустой список участников при входе. Теперь состояние синхронизируется мгновенно при подключении.

## Обновление AI-интеграции (28.03.2026):
Проведён анализ проекта для интеграции AI-сервисов в генерацию и оценку лотов:

### 1. Анализ существующей инфраструктуры:
- Изучены файлы: `README.md`, `dev_log.txt`, `ai-service.js`
- Выявлен отдельный AI-сервис на порту 3002 с API Pollinations.ai
- Сервис предоставляет endpoints: `/generate` (генерация изображений), `/evaluate` (оценка предметов), `/evaluate-multiple` (массовая оценка)

### 2. Реализованные идеи для AI-интеграции:

#### Вариант А: Прямая интеграция в server.js (Рекомендуемый)
**План действий**:
1. Добавить в `server.js` функции-хелперы для вызова AI API
2. Использовать Pollinations.ai напрямую (бесплатный API, не требует ключа)
3. Генерировать изображение лота по промпту с предметом
4. Оценивать предметы по ключевым словам в названии + случайный фактор

**Пример реализации**:
```javascript
// Генерация изображения лота
async function generateLotImage(itemName, description) {
  const prompt = `photorealistic image of ${itemName} on a wooden table, cinematic lighting, highly detailed, 8k`;
  const response = await axios.get(
    `https://image.pollinations.ai/prompt/${encodeURIComponent(prompt)}`,
    { responseType: 'stream' }
  );
  const imageUrl = response.headers['location'];
  return imageUrl;
}

// Оценка предмета
async function evaluateItem(itemName) {
  const keywords = {
    'редкий': 1.5, 'антикварный': 2, 'старинный': 1.5,
    'оригинальный': 1.3, 'винтажный': 1.4, 'коллекционный': 1.8,
    'уникальный': 2
  };
  let basePrice = 100;
  for (const [keyword, multiplier] of Object.entries(keywords)) {
    if (itemName.toLowerCase().includes(keyword)) {
      basePrice *= multiplier;
      break;
    }
  }
  const variance = 0.8 + Math.random() * 0.4;
  return Math.floor(basePrice * variance);
}
```
