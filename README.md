# Аукцион Провидца

## Описание игры

Аукцион Провидца — это захватывающая соревновательная игра для компании друзей, в которой участникам предстоит проверить свою интуицию и чувство рынка. Основная идея заключается в проведении торгов в реальном времени за лоты, истинная ценность и облик которых остаются загадкой до самого финала.

## Правила игры

1. Каждый участник получает стартовый капитал в виде виртуальных монет
2. В начале раунда появляется новый лот с названием, но без изображения
3. Игроки делают ставки, пытаясь угадать реальную стоимость лота
4. По окончании времени торгов раскрывается реальное изображение и цена лота
5. Победителем становится игрок, сделавший последнюю самую высокую ставку
6. Выгода определяется по разнице между ставкой и реальной ценой

## Технические требования

- Многопользовательская локальная игра
- Реализация через веб-интерфейс
- Поддержка нескольких игроков одновременно
- Система синхронизации действий в реальном времени
